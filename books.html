Books

Books provide an excellent way to build a strong foundation in programming, game design, and computational thinking. The resources below are free to read online or borrow digitally, making them accessible to students, educators, families, and beginning game developers.

Free Books and E-books

  • Invent Your Own Computer Games with Python By Al Sweigart. Learn Python by creating simple games while developing programming and problem-solving skills.
  • Making Games with Python & Pygame By Al Sweigart. A beginner-friendly guide to building complete 2D games using Python and the Pygame library.
  • Automate the Boring Stuff with Python By Al Sweigart. Learn Python through practical projects while building a strong foundation in programming concepts useful for game development and other creative coding projects.
  • Open Library Borrow millions of free digital books covering programming, technology, education, and many other subjects.
  • Internet Archive Books Access a large collection of digitized books, manuals, and historical computing resources available to read online.
  • OpenStax Free, peer-reviewed textbooks for higher education, including computer science and related STEM subjects.

Tips for Finding Good Learning Resources

When choosing books about game development, look for resources that:

  • Focus on beginner-friendly programming concepts before moving to advanced game development topics.
  • Include hands-on projects that let you practice by creating games and interactive programs.
  • Explain concepts clearly with illustrations, examples, and step-by-step instructions.
  • Use current versions of programming languages and game engines whenever possible.
