Websites and Videos

Explore these free websites, tutorials, and video channels to learn about programming, game design, digital storytelling, and game development. Begin with a block-based tool such as Scratch, Code.org, or MakeCode Arcade, then explore more advanced engines and programming libraries when you are ready.

Free Websites and Web Resources

  • Scratch Create interactive games, animations, and stories with a beginner-friendly block-based programming language.
  • Code.org Learn computer science through guided lessons, coding activities, games, and classroom resources.
  • Microsoft MakeCode Arcade Build retro-style arcade games using blocks, JavaScript, or Python.
  • Godot Engine Download a free and open-source engine for creating 2D and 3D games.
  • Godot Documentation Read official guides, tutorials, examples, and technical documentation for the Godot Engine.
  • GDevelop Create 2D and 3D games with an open-source engine designed for visual, no-code and low-code development.
  • MIT App Inventor Use block-based programming to create mobile applications, interactive projects, and simple games.
  • Phaser Explore a free JavaScript framework for creating games that run in a web browser.
  • Scratch Ideas and Tutorials Find starter projects, coding cards, project ideas, and guided Scratch tutorials.

Free Videos and YouTube Channels

These channels offer demonstrations, tutorials, design discussions, and complete programming courses. Some videos are intended for older beginners, so younger learners may benefit from help from an adult or educator.

  • Code.org YouTube Watch computer science lessons, classroom activities, student stories, and coding demonstrations.
  • Scratch Team YouTube Watch official Scratch tutorials, project demonstrations, and stories from the Scratch community.
  • Game Maker's Toolkit Learn about level design, game mechanics, accessibility, and the decisions involved in designing games.
  • Brackeys Follow beginner-friendly tutorials about game programming, Godot, Unity, and general development concepts.
  • KidsCanCode Explore programming and game-development tutorials created with young and beginning learners in mind.
  • freeCodeCamp Access free, long-form courses covering programming languages, web development, game engines, and computer science.
  • Godot Engine YouTube Watch official Godot presentations, demonstrations, engine updates, and community showcases.
